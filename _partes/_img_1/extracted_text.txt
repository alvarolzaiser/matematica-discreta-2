Operaciones, Propiedades y Compuertas Lógicas del Álgebra de Boole 
A continuación definiremos los elementos básicos con los que se define 
el Álgebra de Boole, es decir las variables y las operaciones.
· Variables lógicas: solo pueden tomar un valor entre dos opciones ex-
cluyentes, 0 ó 1. En una tubería una llave puede estar abierta (1) o ce-
rrada (0), en un circuito eléctrico un interruptor puede estar abierto 
(0) o cerrado (1), y una lámpara en el mismo puede estar apagada (0) 
o encendida (1). Por lo tanto el estado de los distintos elementos de un 
circuito, se describe usando variables lógicas.
· Operaciones lógicas: las operaciones lógicas permiten combinar va-
riables para poder obtener otras variables. Si bien podrás ver que re-
ciben nombres similares o iguales a algunas operaciones del Álgebra 
clásica, debes tener en cuenta que no tienen nada que ver con ellas, así 
que en esta parte deberás hacer un pequeño gran esfuerzo para abrir 
un poco más la mente y poder formar nuevas estructuras, o también 
podría decirse desestructurar las que ya tienes. Las operaciones son, 
suma lógica, producto lógico y negación.
- Suma Lógica (+): esta operación la podemos relacionar con el conector 
lógico “∨” (disyunción) que estudiamos en lógica proposicional de la MD1.

· Propiedades del Álgebra de Boole. Dentro de las propiedades del Ál-
gebra de Boole haremos la distinción en dos grandes grupos, aquellas 
a las que llamamos Axiomas, que son la base de las demás, ya que ellas 
se toman como válidas o ciertas sin la necesidad de demostrar nada; y 
el otro grupo serán aquellas a las que llamamos Teoremas, que no se 
toman como válidas hasta haberlas demostrado lógicamente.
Veamos entonces cuales son los axiomas que constituyen la base de 
este Algebra:  
· A1: PROPIEDAD CONMUTATIVA  
Para cualesquiera dos elementos, A y B pertenecientes a M, se cumple: 
a- A + B = B + A  
b- A • B = B • A
· A2: PROPIEDAD DISTRIBUTIVA  
Para cualesquiera elementos, A, B y C pertenecientes a M, se cumple:  
a- A • (B + C) = (A • B) + (A • C)  
b- A + (B • C) = (A + B) • (A + C)
 
 
· A3: ELEMENTO NEUTRO  
Existen para cada una de las operaciones un elemento neutro que 
cumple con la propiedad de identidad, esto es:  
a- A + 0 = A  
b- A • 1 = A
· A4: COMPLEMENTO  
Para cada elemento A de M existe otro que oficia de negación o com-
plemento del mismo (Ā), es decir, que cumpla lo siguiente:  
a- A + Ā = 1 
b- A • Ā = 0
