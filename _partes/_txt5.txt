DEFINICIONES
Matrices 
Definiremos MATRIZ, n x m a un conjunto de n.m números dispuestos 
en n filas y m columnas. Diremos que n x m es el ORDEN de la matriz 
(se lee “ene por eme”).
Una matriz 2 x 3 es un conjunto de 2 . 3 = 6 números dispuestos en 2 
filas y 3 columnas. Es de orden 2 x 3.

Entre la gran variedad de matrices que podemos considerar, existen 
algunas que por tener características especiales reciben nombres es-
peciales y aparecen con frecuencia en diversas situaciones y también 
en el desarrollo de los contenidos teóricos. Concretamente es posible 
realizar una clasificación de ellas según su forma y según los elemen-
tos que tengan.
Las matrices, en general son RECTANGULARES pero según cuales 
sean sus elementos o cantidad de filas y columnas tengan, reciben un 
nombre en particular que las identifica: 
MATRIZ NULA
  
Una matriz cuyos elementos son todos ceros se llama matriz nula y se 
simboliza por 0 Una matriz nula no necesita ser cuadrada.
En símbolos:  
A n x m es nula ⇔ aij  = 0 para todo i,j
Ejemplo:  
 
                0   0   0   
03x3 =     0   0   0                 01x3 =     0   0   0  
                0   0   0 
 
La matriz nula puede ser también una matriz fila o una matriz columna. 
MATRIZ CUADRADA
Llamaremos matriz cuadrada a aquella que tiene el mismo número de 
filas que de columnas.
Ejemplo:

                3   2   1

En el caso de una matriz cuadrada no es necesario indicar el número de 
filas y de columnas porque ambas son iguales. Basta decir que es una 
matriz cuadrada de orden n.
Además, en una matriz cuadrada distinguimos la diagonal principal y la 
secundaria. Los elementos de la “diagonal principal” son los que están 
desde el ángulo superior izquierdo al inferior derecho y los elementos de 
la “diagonal secundaria” son los que están desde el ángulo inferior iz-
quierdo al superior derecho. Esto es válido sólo para matrices cuadradas.

MATRIZ IDENTIDAD O MATRIZ UNIDAD
Definiremos matriz identidad como una matriz cuadrada que tiene los 
elementos de la diagonal principal iguales a uno y los restantes son ceros.
En símbolos:  
A n x n es identidad ⇔    aij = 1 cuando i = j 
                                              aij = 0 cuando i ≠ j
Se la simboliza en general con una i mayúscula y un subíndince para 
indicarnos el orden: I n.
En cada orden matricial existe una matriz unidad, por ejemplo:
            1   0                     1   0   0
I2 =     0   1          I3=     0   1   0   
                                        0   0   1 
 
 
MATRIZ TRIANGULAR  
 
Es una matriz cuadrada que tiene nulos todos los elementos que están 
a un mismo lado de la diagonal principal. Las matrices triangulares 
pueden ser de dos tipos: 
Triangular Superior: Si los elementos que están por debajo de la diago-
nal principal son todos nulos. ( En símbolos: aij > j )
               
         
Triangular Inferior: Si los elementos que están por encima de la diago-
nal principal son todos nulos. (En símbolos: aij = 0 para todo i < j )

IGUALDAD DE MATRICES 
Dada dos matrices A y B, estas serán iguales si: 
1| Son del mismo orden.  
2| Si los elementos correspondientes (los que ocupan el mismo lugar) 
son iguales.
Elementos correspondientes en matrices son aquellos que tienen igual 
par de subíndices ij.
