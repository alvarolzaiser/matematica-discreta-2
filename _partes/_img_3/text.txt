Ahora entonces sí, sigamos adelante.
Así como vimos en la MD1, una función es una relación entre dos va-
riables, para la que se debe cumplir que una variable independiente se 
debe relacionar con una y solo una variable dependiente, en el Álgebra 
de Boole también existen funciones, que llamamos justamente Boo-
leanas, que resultan de combinar un número de variables mediante las 
tres operaciones ya definidas.
Un ejemplo de función como las que vimos en el cuatrimestre anterior se-
ría f (x) = 2 x + 3 en ella decimos que si x toma el valor 1, la función vale 5, 
f (1) = 5; si x toma el valor 4 la función vale 11, f (4) = 11; y así con cualquier 
valor que le querramos dar a la variable x será otro valor el de la función.
La gran diferencia entre estas funciones y las Booleanas es que, como 
ya lo dijimos desde el principio, las variables solo pueden tomar el va-
lor 0 ó 1. Entonces si una variable vale 0, la función podría ser 0 ó 1, y si 
la variable fuera 1, la función podría ser solo 0 ó 1.
Un ejemplo de función Booleana con una sola variable puede ser: F (B) = B 
Para esta función, si B toma el valor 0, la función vale 1, y viceversa, es 
decir: F (0) = 1 y F (1) = 0
 
Pero lo más común no es que las funciones sean de una sola variable 
sino dos o más. Por ejemplo la siguiente: F (A, B) = A . B 
En este caso entonces, ya no solo es una variable la que puede tomar 
los valores 0 ó 1, sino dos, por lo que las posibles combinaciones que se 
pueden dar para los valores de las variables son 4. Por ejemplo si A vale 
0 y B vale 0, la función valdría 0, es decir F (0,0) = 0 . 0 = 0 . 1 = 0.
Si A vale 1 y B vale 0, la función valdría 1, es decir: F (1,0) = 1 . 0 = 1 . 1 = 1
Le dejo como actividad para resolver ahora mismo, encuentre el valor 
de la función anterior para las dos posibles combinaciones que faltan.
Así mismo podemos seguir escribiendo funciones Booleanas con tres, 
cuatro, cinco o más variables, como por ejemplo: 
F (A, B, C) = (A + C) . B + Ā  
F (A, B, C, D) = D . B + C + A . B
Encuentre el valor las funciones arriba escritas, para los siguientes 
valores de las variables: 
F (1,1,0) y F (0,1,0) 
F (0,1,0,1) y F (1,0,1,1)
Así como las funciones toman un valor dependiendo el valor 0 o 1 que 
tome cada variable que interviene en ella, a los fines de conocer el 
resultado para todas las posibles combinaciones resulta mucho más

dos que corresponden al complemento de la suma y del producto.
Las compuertas lógicas para cada operación son las siguientes:
 
Función                               Compuerta                               Símbolo
F(A,B) = A + B                                    OR
F(A,B) = A • B                                   AND

F(A,B) = A + B                                  NOR
F(A,B) = A · B                                 NAND
Si observas bien podrás notar que en casi todos los casos puede haber más 
de una entrada, pero siempre habrá una sola salida. Veamos entonces un 
ejemplo, en el que debamos hacer el circuito lógico para una función.
Tomemos la función F (A, B, C) = Ā + B + B . C
Entonces a partir de las tres variables de entrada armamos el siguiente

                A   B     C

De esta manera hemos llegado a poder escribir o representar una fun-
ción Booleana de tres modos diferentes, mediante su expresión alge-
braica, su tabla de verdad y su circuito lógico. Es por esto que si hay tres 
maneras de escribir la misma función, seguramente se puede pasar de 
una a otra, es decir si tengo la expresión algebraica poder hacer el circui-
to y la tabla, o si tengo la tabla hacer el circuito y la expresión algebraica, 
y lo mismo si tengo el circuito lógico. Para poder escribir la expresión 
algebraica a partir de los resultados de la tabla de verdad, necesitamos 
ver un modo especial de escribir una función Booleana, que llamamos 
forma canónica de ella...pero ese será tema de la próxima clase.
